SDR receiver compatible with HPSDR Protocol 2 (extrawide, up to 1536 ksps)

The SDR receiver is ready.

Note: this receiver uses the cache-coherent ACP/DMA data path. Reboot the board before switching to the other openHPSDR Protocol 2 receiver (or to another app) — reprogramming the FPGA while the ACP port is active hangs the DMA.

Now you can run the SDR programs that support the openHPSDR Ethernet Protocol 2. This receiver presents up to 4 DDCs at sample rates of 48/96/192/384/768/1536 ksps (1536 ksps gives ~691 kHz usable bandwidth; work in progress).

SDR programs

Here is a list of the SDR programs that are known to work with the openHPSDR Protocol 2:

  • linhpsdr (Linux)
  • piHPSDR (Linux / Raspberry Pi)
  • Thetis (Windows)
